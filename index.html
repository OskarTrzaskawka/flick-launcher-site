Before you install

Where are Repair and Uninstall?+

Install using Setup. In Flick, open Settings → General → Installation. You can also reopen Setup, use Windows Settings → Apps, or run Uninstall Flick Launcher.exe from the installation folder. Portable has no uninstaller.

Does a local account work on every server?+

No. Local names work in singleplayer and on servers that accept them. Flick has no Microsoft sign-in and does not grant a Minecraft licence.

Will my local skin appear in game?+

Local skins require CustomSkinLoader in a compatible modded profile. Other players need compatible skin support too.

Can Android run every Minecraft version?+

No. Game versions, Java runtimes, graphics drivers and available memory affect compatibility. This APK is an alpha; native 16 KB page-size support remains incomplete.
