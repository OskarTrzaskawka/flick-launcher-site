03 / DEVELOPMENT NOTES

A work in progress.
With a clear direction.

Flick is an early preview. Here is what the current build does, and what still needs work.

IN THE CURRENT PREVIEW

The foundations are here.

  • Isolated profiles and local player accounts
  • Releases and recent snapshots from Minecraft 1.13 onward
  • Automatic Java installation on Windows x64
  • Modrinth discovery and individual add-on installation
  • Modrinth modpack imports and world backups
  • Discord activity with game version, session time and privacy controls
  • 3D Wardrobe, local skin library and owned Microsoft capes
  • Polish and worldwide server discovery with saved favourites
  • Windows tray, optional autostart and configurable close behaviour
  • File names, transferred KB/MB and filtered session logs
  • Startup checks for Vanilla and four mod loaders on 1.21.1
STILL BEING BUILT

More to come.

  • Microsoft sign-in availability, subject to configuration and API access
  • Historical versions, including Alpha and Beta
  • Broader compatibility testing across Windows versions
  • Lower memory use, measured on real devices
  • Refined artwork, modpack updates and easier recovery
  • A public release and automatic launcher updates

A note on performance. We have not benchmarked Flick against the official launcher. Windows 7 support is not available in the current Electron build, and the newest Minecraft versions have their own system requirements.

04 / A FEW GOOD QUESTIONS

Before your
next adventure.

Is this an official Minecraft launcher?＋

No. Flick Launcher is an independent project and is not affiliated with, endorsed by, or approved as an official product by Mojang Studios or Microsoft. Minecraft belongs to its respective owners.

Can I download it yet?＋

Yes. The Windows x64 development preview is available from the project's GitHub release. Choose Setup to install or Portable to run without installation. Both builds are unsigned and remain an early preview. Windows 7 is not supported by this build.

Do I need to own Minecraft?＋

Flick does not grant a Minecraft license. Microsoft-authenticated play requires an account entitled to Minecraft: Java Edition. Local profiles do not provide ownership or access to servers requiring Microsoft authentication.

Does Microsoft sign-in work in the preview?＋

The integration exists, but sign-in is not enabled in the default preview. It requires the project's own Microsoft application registration, suitable Minecraft Services access and end-to-end account testing. The launcher does not collect Microsoft passwords in its own interface.

What about Windows 7 and older Minecraft versions?＋

They are development goals, not current compatibility claims. The present Windows x64 build uses modern Electron. Alpha, Beta and releases before Minecraft 1.13 need additional launch support. A launcher's compatibility cannot guarantee that every game or Java version will run on an older computer.

Will my local skin appear in Minecraft?＋

Flick can preview and store local skins and capes. To use them in game, enable CustomSkinLoader from Wardrobe in a supported modded profile. Vanilla Minecraft does not load custom offline textures automatically; other players need compatible skin support to see them.

Can I install shaders and resource packs?＋

Yes, the preview can download compatible content from Modrinth into a selected profile. Shaders also require an appropriate shader-support mod and need to be enabled in game. Resource packs are selected in the game's resource-pack menu.
