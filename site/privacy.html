This website

This is a static information website for Flick Launcher. It has no sign-in, contact form, advertising, analytics script or tracking cookies. Fonts and screenshots are served with the site. Your animation preference is saved in your browser's local storage if you use that setting.

Hosting and external links

When hosted on GitHub Pages, GitHub operates the hosting infrastructure and may process technical request information under its own policies. See the GitHub General Privacy Statement. Following a link to GitHub, Minecraft or another service takes you to that service's own website and policies.

The desktop launcher

The desktop launcher is a separate application. The preview stores profiles, settings, worlds and downloaded content on the user's computer. It contacts Minecraft distribution services, Java runtime providers and Modrinth for requested content. Microsoft account integration, when configured and available, contacts Microsoft and Minecraft authentication services. The website does not receive these account sessions.

In the current preview, Microsoft refresh tokens are stored locally using Windows-backed encryption through Electron safeStorage. Microsoft sign-in has not been enabled or verified in the default development build. This website does not ask for Microsoft credentials or tokens.

Wardrobe and server discovery

When requested, the launcher contacts Craftdex, Minecraft Java Servers and Cloud Client to retrieve skin or server directories. These providers receive the network request, including the public IP address. Visible server cards also request status from mcsrvstat.us, which receives the server address being checked and the network request. Modrinth icons and server icons are cached locally; cached status and icons reduce repeat requests. Minecraft textures come from Mojang's texture servers. Imported skins, capes, favourites and cached directories are stored on your computer. Username skin lookup queries Mojang services; Microsoft skin and cape changes use the selected account's Minecraft session. Optional CustomSkinLoader is downloaded from Modrinth and follows its own settings and privacy behaviour.

Windows integration

Starting with Windows is optional and disabled initially. Enabling it registers a startup entry on the device. Closing to the tray keeps the local launcher process running until Quit is selected. The website does not receive these settings or local logs.

Discord activity

The desktop preview can communicate with the locally running Discord desktop client to share launcher activity, the game version, mod loader and session time. The last detected server address is included when server sharing is enabled. Activity and server sharing can be turned off in Settings, including while the game is running. World names and Microsoft credentials are not part of this activity. Discord processes shared activity under its own policies. This website does not receive it.

Contact and feedback

Support, suggestions and enquiries about optional development donations are handled on the Flick Discord. Discord handles messages and account information under its own policies. GitHub issues may also be public. Do not post passwords, session tokens or payment credentials in public channels.

Project status

Flick Launcher is independent software, currently under development. It is not affiliated with Mojang Studios or Microsoft. This page describes the current preview and will be revised as the product changes.
